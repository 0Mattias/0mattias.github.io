bettermemory

A trust layer between an AI coding agent and its own past.

v3.27 · MIT · works with Claude Code, Cursor, and any MCP client

Memory tools for AI agents are good at storing facts and silent about whether a fact is still true. Files move, projects pivot, preferences change, and the stored note from March reads as gospel in November. A confidently remembered stale fact is worse than no memory at all.

bettermemory is built around that gap. It is a local MCP server (plain markdown on disk, no cloud, no database), but the store is the substrate, not the point. The point is trust: a stored fact is treated as a claim that has to keep earning belief. It is verified against the filesystem and git before the agent relies on it, attributed down to the sentence it shaped when it gets used, measured for whether it actually helped, and owed a public postmortem when a verdict is wrong.

sixty seconds, offline

bettermemory try runs the machinery in a throwaway store: it writes a memory citing a file, deletes the file, and the next search comes back flagged stale.

uv tool install bettermemory
bettermemory try

install

Claude Code:

/plugin marketplace add 0Mattias/bettermemory
/plugin install bettermemory@bettermemory

Elsewhere: uv tool install bettermemory then bettermemory init --client <name>
